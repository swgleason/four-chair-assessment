# Scoring system for the four chair assessment

## 1. Structure

There are 28 questions in four sections of 7. Each section is tied to a "chair" (chair 1 = Q1-7, chair 2 = Q8-14, chair 3 = Q15-21, chair 4 = Q22-28).

- **Section 1** uses Disagree / Unsure / Agree.
- **Sections 2-4** use Weak / Improving / Strong.
- Every question is keyed so the third option is the "desired" answer.

## 2. Points per answer

Points depend on the index of the button tapped:

| Button | Points |
|---|---|
| 1st (Disagree / Weak) | 0 |
| 2nd (Unsure / Improving) | 2 |
| 3rd (Agree / Strong) | 3 |

- **Section score:** the sum of 7 answers, so 0 to 21.
- **Achievable totals:** every integer from 0 to 21 except 1.
- **Storage:** answers go in `scoresObj[chair][questionId]`.
- **Changing an answer:** overwrites that question's entry.

## 3. When scoring runs

After each answer, `position` increments. When `position % 7 == 0` (after Q7, 14, 21, 28), `calculateScore()` runs.

- If it sets `chairScore > 0`, the quiz ends immediately: `isCompleted = true`, and results are saved.
- If `chairScore` is still 0, the user passed that section and the quiz continues.
- The assessment can therefore end after 7, 14, 21, or 28 questions.

## 4. Pass/fail thresholds and placement

`calculateScore` loops through the chairs answered so far, in order, sums each one, and stops at the first failure.

| Section | Pass if | If failed, placed in | Score used for the fraction |
|---|---|---|---|
| 1 | ≥ 18 | Chair 1 | Section 1 score |
| 2 | ≥ 14 | Chair 2 | Section 2 score |
| 3 | ≥ 14 | **Chair 2** | **Section 2** score |
| 4 | ≥ 14 | **Chair 3** | **Section 3** score |
| 4 (passed) | n/a | Chair 4 | Section 4 score |

The placement is offset by one for sections 3 and 4.

- Failing section 3 sends you back to Chair 2 using the section 2 score.
- Failing section 4 sends you to Chair 3 using the section 3 score.
- Section 3's own score is only used if you pass it and then fail section 4.
- The code does this with `p = s - 1` and `setChairScore(u - 1, t[p].score)`.
- Section 4 always ends the quiz, either as Chair 4 (≥14) or Chair 3 (<14).

**What the thresholds mean in practice**

- **Passing section 1 (≥18)** requires one of these combinations:
  - 7 Agree (21)
  - 6 Agree + 1 Unsure (20)
  - 5 Agree + 2 Unsure (19)
  - 6 Agree + 1 Disagree (18)
  - 4 Agree + 3 Unsure (18)
  - All Unsure is only 14, so it fails.
- **Passing sections 2-4 (≥14)** can be done with all 7 "Improving" (7 × 2 = 14). Other mixes also work, such as 2 Strong + 4 Improving + 1 Weak.

## 5. The fractional chair score

`setChairScore(chair, score)` computes `chairScore = chair + score / 21`. Then:

1. **Special case for a perfect section.**
   - If chair = 2 and score = 21, the result is forced to **2.9**.
   - If chair = 3 and score = 21, the result is forced to **3.9**.
   - This keeps a perfect score from computing to 3.0 or 4.0 and bumping the person up a chair.
   - There is no special case for chair 1 (a score of 21 can't occur there) or chair 4.
2. **Rounding and cap.** The value is rounded to 2 decimals (`toFixed(2)`). If it is ≥ 5 (Chair 4 with a perfect 21), it is capped at **4.9**.

**Resulting ranges**

| Outcome | Reached by | Formula | Range |
|---|---|---|---|
| Chair 1 | S1 < 18 | 1 + S1/21 | 1.00 – 1.81 |
| Chair 2 (failed S2) | S1 ≥ 18, S2 < 14 | 2 + S2/21 | 2.00 – 2.62 |
| Chair 2 (failed S3) | S1 ≥ 18, S2 ≥ 14, S3 < 14 | 2 + S2/21 | 2.67 – 2.95, or 2.9 if S2 = 21 |
| Chair 3 | S1, S2, S3 passed, S4 < 14 | 3 + S3/21 | 3.67 – 3.95, or 3.9 if S3 = 21 |
| Chair 4 | all passed | 4 + S4/21 | 4.67 – 4.95, or 4.9 if S4 = 21 |

**Consequences of the special cases**

- **Non-monotonic top end.** A score of 20 gives x.95 but a perfect 21 gives x.9. This applies to chairs 2, 3, and 4.
- **Chair 2 fractions show the route.** A fraction under 2.67 means section 2 itself was failed. A fraction of 2.67 or higher means section 2 was passed but section 3 was failed.
- **Chairs 3 and 4 always start high.** The fraction is always at least 3.67 or 4.67, because the score used must have passed the ≥14 threshold.

## 6. How the result is displayed

- "You are in Chair N" uses `floor(chairScore)`.
- The progress bar uses the full decimal.
- The label text comes from a `chairType` pipe (its definition isn't in this file).
- The intro video shown is `chairVideos[floor(chairScore)]`.

## 7. "Where should I focus?" (focus responses)

While summing each chair, any question answered with **0 points** (Disagree/Weak) may add its `focus_response` text to `focusResponses`. "Unsure" and "Improving" never trigger one.

- **Chair 1 questions:** added only if the list is currently empty. All seven share the same paragraph, so chair 1 contributes at most one item.
- **Chairs 2-4 questions:** added while the list has fewer than 4 items.
- **Duplicates:** skipped via `indexOf`.
- **Cap:** the list never exceeds 4 items, including any chair 1 item.
- **Order:** chair 1 first, then chair 2, 3, 4, each by question number.
- **Failing chair included:** the failing chair's questions are summed before the threshold check, so its weak items are included. This means someone placed in Chair 2 by failing section 3 can see focus items from section 3.
- **Early chairs fill the list first:** if sections 1 and 2 already produce 4 items, weak answers in later sections never appear.
- **Display:** the "Where should I focus?" header only shows if the list is non-empty.

## 8. The saved data

`calculateScore` returns an array `t` with one entry per chair, shaped `{score, focusOn}`. The chair where the user is placed gets `focusOn = true`, or the previous chair in the section 3 and 4 failure cases. Chairs never reached stay as empty objects.

When the quiz completes, `setUserAssessmentResults` saves:

- the user
- the fractional chair score
- the answers (question, chair, answer, answer index; choices and focus text are stripped)
- the `t` array
- the focus responses
- the history

It also does the following:

- **History:** appends `{chair, completed_at_unix}`. If a legacy record has `chair` but no `history`, it migrates the old result in first.
- **User profile:** if the user's stored `chair` differs from the new score, it updates it with `updateUserChair`.

## 9. Retake and reset behavior

- **Retake** (`restartQuiz` → `loadQuestions(false)`): resets `chairScore`, `position`, `isCompleted`, `scoresObj`, `focusResponses`, and rebuilds fresh questions.
- **Continue** (`continueQuiz`): reuses the in-memory question set and existing state.
- **Progress:** `percentCompleted = round(position / 28 × 100)`.

## 10. Edge cases and quirks

1. **Section 3 failure ignores section 3's score.** This is the offset described in section 4.
2. **Stale focus items.** `focusResponses` is only cleared on a full restart. If a user goes back across a section boundary and changes answers, old focus items stay in the list.
3. **Stale answers after going back.** `goBack` only decrements `position`; `scoresObj` entries are kept. If the user backs up and re-answers earlier questions, answers from later sections they had already given are still in `scoresObj`. At the next boundary they get scored too, which can make the quiz jump ahead using old answers.
4. **Loop order assumption.** `calculateScore` relies on chair keys being consecutive from 1 (`s` is a running index). That holds in normal flow.
5. **No reset between boundary checks.** `focusOn` and scores are recomputed each time, but `focusResponses` accumulates (see item 2).
6. **Placeholder text.** The `chairDescription` strings ("This is the Chair 1 Description") are unused placeholders.
7. **Leftover logging.** The `console.log` calls have no effect on scoring.

## Pseudocode

```
for each section 1..4 as you finish it:
    S = sum(points of its 7 answers)          // 0, 2, or 3 per answer
    collect focus items for 0-point answers   // see section 7

    if section 1: if S < 18 → Chair 1, fraction = 1 + S/21, stop
    if section 2: if S < 14 → Chair 2, fraction = 2 + S/21, stop
    if section 3: if S < 14 → Chair 2, fraction = 2 + S2/21, stop
    if section 4: if S < 14 → Chair 3, fraction = 3 + S3/21, stop
                  else      → Chair 4, fraction = 4 + S4/21, stop

    // special cases applied to the fraction:
    if (chair 2 or 3) and score == 21 → fraction = chair + 0.9
    round to 2 decimals; if ≥ 5 → 4.9
```
